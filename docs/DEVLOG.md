## 阶段复盘：从 "简单总结" 到 "知识重组编译器"

在第一阶段（v1 版本）的设计中，我们试图用传统的 Web 思想来解决视频提炼问题：
- 将转录出的段落片段、高亮点等结构平铺在本地内存或简单的伪数据库表中。
- 对本地视频采用物理切割 FFmpeg 文件，通过多线程并行转录后进行大模型总结拼装。
- 但这样做的缺陷是显而易见的：视频片段被硬生生切断后丢失了上下文连续性，而且视频库管理与用户已有的个人知识库（例如 Obsidian / Logseq）完全脱节。

于是，在 **v2.0.0** 架构中，我们彻底推翻了旧的设计，引入了 **无数据库 (Database-less) 的米兰之书 (MilanoBook) 编译规范**。

## 存的彻底颠覆：无数据库规范设计

“既然最终目的是将音视频提炼为可沉浸阅读的书籍，那为什么我们不直接用文件的目录结构来组织这一切？”

### 1. 结构重组与动态知识库挂载
我们抛弃了任何传统数据库服务，将存储中心定义为一个 **Active Root Directory**。
在前端，我们通过定制开发的 `FileExplorer` 与后端 `/api/books/settings/browse`、`root` 联动，支持用户像在 IDE 中选择 Workspace 一样，自由指定、浏览、切换宿主机磁盘上的任何绝对路径：
- 当用户选定了一个路径，系统会在其中静默创建一个由 UUID 组成的书籍文件夹。
- 文件夹内部存储有 `book.json` (基本元数据)、`index.json` (树状大纲)、`raw.json` (原始全片高保真字幕) 以及 `segments/` 文件夹。
- `segments/` 内包含了每一个叶子节点的细节 Markdown。
- 这个物理层面的完全解耦，让它天然兼容 **Obsidian** 笔记库。每一个 MilanoBook 都可以作为 Obsidian 中的一个独立文件夹，通过双链或搜索完美引用。

### 2. 3 阶段 AI 编译流 (3-Phase Compilation Pipeline)
另一个重大的革新是彻底弃用了物理文件分片。物理切割媒体文件容易造成句法被拦腰截断，造成 ASR 及总结质量急剧劣化。

我们实现了一套基于 **流式合并 + 语义章节感知** 的 3 阶段重构：
- **第一阶段 (Outline Generation)**：
  - 不做任何物理切割。我们直接抓取在线字幕（或对全片媒体做一次完整的 ASR 提取，得到带有浮点时间戳的段落数组）。
  - 将完整的、连续的、带时间戳的原文，配合 strict JSON Schema 丢给大模型。
  - 大模型利用结构化输出 (Structured Outputs)，一次性生成完美契合视频语义的树状大纲树 (`outline.json`) 以及全局总结。这避免了大模型在起草大纲时进行二次幻觉，也确保了大纲中绝对不带有任何层次序号（序号由系统在拼装时自动格式化补充）。
- **第二阶段 (In-memory Logical Slicing & Parallel Leaf Summaries)**：
  - 提取出大纲中的全部 “叶子章节” (Leaf Nodes)，每个叶子章节拥有严格不重叠且覆盖全片的 `[start_seconds, end_seconds]` 区间。
  - 在内存中切片字幕数组，提取出对应时间区间内的口白。
  - 通过异步协程池并行启动多路大模型，采用 **学术讲演风格** (知识高保真) 对各分段进行提炼。我们严令大模型在总结时禁止遗漏任何细节，必须如实还原公式（LaTeX格式）、代码块、参数指标，并纠正语音识别中的同音错字。
- **第三阶段 (DFS Assembly & Markdown Recomposition)**：
  - 对大纲树进行递归的深度优先遍历 (DFS Walk)。根据当前大纲节点的深浅，自动计算并附加格式化的序号（一、二、1.1.、1.1.1.）。
  - 读取每个叶子对应的 `segments/{uuid}.md`，并最终合并导出为单本大容量的、精美排版的 `complete.md`。

这一套编译链路测试下来，大模型对于学术、技术分享类视频的编译解析效果达到了惊人的精度。公式渲染完美，代码格式严谨，完全消除了繁冗的废话。

## 取的进阶：跨书整合笔记 Aggregator

在能够编译出高质量 MilanoBook 后，很自然会面临一个问题：*“如果我想将多篇相关的视频知识融合到一起，该怎么办？”*

这就是 **Aggregator (多书整合)** 的用武之地：
- 用户可以自由跨视频选择多本已经编译完成的 MilanoBook。
- 输入定制的学习/分析 Prompt 指向。
- 后端服务提取选定书籍的 Outline 层次及核心正文段落，组合成超长的学习上下文，呼唤最强大模型对其进行融会贯通。
- 最终产出不仅包含对多个视频观点的合并与比较，更生成了一份结构极度严谨的、可以直接放入 `.notes/` 文件夹下的整合学习手册。

## 视觉交互：等宽、直角与像素霓虹

在 UI 层面，我们坚持了 **Retro-futurism (复古未来主义极简风)** 的极简设计规范：
- 废除所有圆角、渐变与磨砂玻璃特效（使用 `rounded-none`）。
- 全站采用 `JetBrains Mono` 等宽字体，包括按钮、输入框、阅读文本。
- 背景采用深邃空无的 `#0a0a0f`。
- 高亮区域通过霓虹青 (`#00f0ff`) 和霓虹品红 (`#ff00a0`) 做对比，给用户一种老式计算机终端编译、归档知识资产的强烈仪式感。
- 我们利用 `ReactMarkdown` + `remark-gfm` + `remark-math` + `rehype-katex`，对生成的 `complete.md` 进行科学排版渲染。点击总结中带有的时间戳 `[MM:SS]`，前端阅读器会自动调度视频播放器（或跳转至对应的外部定位流），真正实现了“阅读一本书的同时与音视频媒介深度互动”。

## 未来展望与待办

- [ ] **多模态图文混排（Multimodal Tokenization）**：后续希望引入 FFmpeg 在 Phase 2 切片时，智能抽取关键帧图像。在大模型处理 Leaf Nodes 时，同时传入对应的帧图像做视觉分析，在 MD 文本中自动注入 `![frame](path)` 标记，实现彻底的图文并茂。
- [ ] **增强本地 Whisper 音轨分离**：对吵杂的视频，增加一步高精度人声剥离 (De-noise / Vocal Split)，从而大幅提升本地 faster-whisper 的语音识别率。
